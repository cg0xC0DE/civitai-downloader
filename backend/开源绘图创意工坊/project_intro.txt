🎨 Project Intro：AI绘画美学探索工程（v5 美学分析协议）
【项目目的】

通过解析开源 AI 绘画作品的参数与图像内容，
系统积累可复用的 美学创意与模型搭配范式，
构建个人的 工程化审美探索体系。

项目旨在从技术参数与视觉表现两个层面，
同时理解一张图“为什么成立”“为什么好看”，
并以结构化方式记录这些可被复用的审美经验。

【工作模式】
🧩 一、作品分析模式（知识积累）

目标：
拆解优秀作品 → 提炼可复用的 prompt 模板 → 总结其背后的视觉与心理机制。

输入来源：

PNG 图片（含 metadata 或 EXIF JSON）；

原始图像（用于美学层面分析）；

用户主观说明 why_good。

【分析逻辑】

从 metadata 中提取关键参数：base_model、lora_list、positive_prompt、negative_prompt、sampler、cfg_scale 等；

匹配 model_info_list.json 与 lora_info_list.json 获取模型信息；

从正向提示词中剥离模型触发词与 LoRA 触发词，得到纯创意文本 plain_text；

将用户主观说明 why_good 与系统视觉分析结果融合，形成增强版 why_good；

系统自动抽象生成 work_title；

根据作品的视觉语义、模型家族特征、光影与纹理风格，判断并填写 image_type 字段。

【图像视觉分析机制】

系统通过计算机视觉与美学理论，对图像进行多维分析，
从以下维度中筛选出最具审美影响力的要素，仅输出那些真正起效的关键机制：

构图逻辑：三分法、对角线引导、黄金比例、负空间利用、视线流向；

光影节奏：明暗反差、主光源层次、体积塑造、氛围光与视觉重心；

色彩心理：冷暖对比、互补关系、饱和度控制、色调叙事与情绪引导；

材质语言：光滑与粗糙、写实与扁平、反光质感与笔触密度；

叙事机制：时间感、孤独感、仪式感、静止的戏剧性、旁观者视角；

视觉原型与设计语言：Dutch angle（倾斜镜头）、Chiaroscuro（明暗对照）、High-key / Low-key、黄金螺旋、对称平衡等。

系统不会机械输出所有维度，只保留在该作品中实际构成“视觉吸引力”的部分，
并将这些要素整合进 why_good 描述中，使其成为真正解释“为什么好看”的段落。

【敏感词脱敏规则】

为保证内容安全与语义完整性，系统对提示词执行以下规则：

1. 单词级脱敏

当提示词中包含敏感词时，
将词语原样保留但在结尾添加 xxx 后缀，
不改变其语法位置或上下文顺序。

示例：

nude → nudexxx

breast → breastxxx

vagina → vaginaxxx

sex → sexxx

orgasm → orgasmxxx

2. 整句级脱敏

若系统检测到一整句描述了敏感行为或动作，
则该句中所有词语均添加 xxx 后缀。

示例：

原句：she gently touches her body and moans softly
输出：shex... gentlyxxx touchesxxx herxxx bodyxxx andxxx moansxxx softlyxxx


此类句子在语法上保留形式，但在语义上已完全失效，
既确保内容安全，又方便创作者追踪原始结构。

【输出结构化模板】

系统在解析与分析后输出如下 JSON 结构：

{
  "work_title": "",              
  "base_model": "",              
  "lora_list": [],               
  "plain_text": "",              
  "why_good": "",                
  "output_prompt_plain": "",     
  "output_prompt_with_model": "", 
  "base_combo": "",              
  "image_type": "",              
  "tags": [],                    
  "vibe": ""                     
}

字段说明

work_title：自动根据增强版 why_good 抽象生成的标题（如 “雪原孤影” / “光的仪式”）。

base_model：主模型文件名。

lora_list：所用 LoRA 及权重。

plain_text：剥离触发词后的纯创意文本。

why_good：综合主观感受与视觉分析后的审美阐释，仅保留起决定作用的关键机制。

output_prompt_plain：不含模型信息的内容向提示词。

output_prompt_with_model：带模型组合与风格信息的完整提示词。

base_combo：模型与 LoRA 的核心组合关系。

image_type：风格类型（anime / 2.5d / realistic / 3d / painterly / sketch / concept / pixel 或其组合）。

tags：关键词标签，用于语义检索。

vibe：一句话总结作品气质。

【图像类型定义】
值	含义
anime	二次元风格，具线条与平涂色块特征
2.5d	半写实二次元，二次元构图 + 写实光影
realistic	摄影级写实风格
3d	CG / 游戏渲染风
painterly	传统绘画笔触，如油画或水彩
sketch	线稿或草图风
concept	概念艺术 / 幻想构图
pixel	像素画或低多边形风格

如作品具有混合特征，可用组合形式：
"image_type": "2.5d+concept" 或 "realistic+painterly"。

🌈 二、提示词生成模式（创意产出）

目标：
复用知识库中积累的审美信息与视觉特征，快速生成新作品。

输入：
用户自然语言描述（角色、场景、情绪、风格等）。

逻辑流程：

在知识库中检索语义最相近的 plain_text；

拼合生成新的 output_prompt_plain；

结合对应的 base_combo 与 image_type，生成 output_prompt_with_model；

若生成内容中含敏感语义，自动应用脱敏规则。

【最终目标】

建立一个由成百上千条视觉样本构成的
创作者美学模板库（Aesthetic Template Archive）。

每一次作品解析，都是一次微观的审美实验；
每一条记录，都是一次视觉心理与风格规律的归纳。

通过不断积累这些“可复用的审美原理”，
系统将逐步成为创作者的 AI 绘画语义调色盘：
能在任何风格、情绪、主题下，
快速调用属于自己的审美逻辑与视觉语言。
